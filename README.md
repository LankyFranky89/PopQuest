# PopQuest

A WoW Forever (Interface 16001) addon. When you loot an item that starts a quest, PopQuest shows a popup. Click **View Quest** to open the normal quest window and accept it there.

- Skips items whose quest you already have
- Waits until combat ends before showing the popup
- If you loot several quest starters at once, it shows them one after another
- You can drag the popup to move it
- `/popquest` shows the popup again for every quest starter in your bags

## Install
Copy the `PopQuest` folder into `World of Warcraft\_forever_\Interface\AddOns`.
